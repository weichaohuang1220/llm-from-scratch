## ⏱ 接下来 15 分钟：10 个必答题（每题 1 分钟）

### 1. 为什么 RMSNorm 不是 LayerNorm？
不减均值、只除 RMS。**计算更快，效果相当**，现代 LLM 标配。公式：`y = x / sqrt(mean(x²)+ε) × γ`

### 2. RoPE 是什么？
把位置编码成**旋转角度**，每个维度对按 `pos × θ_k` 旋转。**相对位置天然可建模**，Q·K 点积只依赖相对距离。

### 3. GQA 和 MHA/MQA 区别？
Q 有 N 头，KV 有 G 头（G<N）。MiniMind 是 8 Q + 4 KV，每 2 个 Q 共享 1 组 KV。**推理时 KV Cache 显存减半**。

### 4. SwiGLU 怎么算？
`down(SiLU(gate(x)) ⊙ up(x))`——有"门控"机制，gate 分支过 SiLU 激活，和 up 分支相乘，再降维。比 ReLU 平滑、比普通 FFN 效果好。

### 5. Pre-Norm vs Post-Norm？
Pre-Norm：`x + SubLayer(Norm(x))`，残差路径干净，训练稳定，**不需要 warmup**。现代模型都用这个。

### 6. SFT 和预训练的 loss 区别？
**SFT 只对 response 算 loss，prompt 部分 label 设 -100 忽略**。因为目标是"学怎么回答"不是"学怎么提问"。

### 7. LoRA 原理？
假设权重变化量 ΔW 是低秩的，训练 `ΔW = B×A`（A是(r,d)，B是(d,r)，r一般=8）。**只训练 0.5% 参数**，推理时可合并。

### 8. DPO 和 RLHF 的区别？
DPO 数学推导证明**不需要显式 Reward Model**，直接用 pairwise（chosen/rejected）数据优化。
Loss：`-log σ(β × [log π(y_w)/π_ref(y_w) - log π(y_l)/π_ref(y_l)])`

### 9. GRPO 核心创新？
DeepSeek 提出，**去掉 Critic（value model）**，对同一 prompt 采样 G 条回答，用组内相对 reward 做 advantage。**省一半显存**。

### 10. KV Cache 是什么？
推理时缓存历史 token 的 K/V，每步只算新 token 的。把 O(N²) 降到 O(N)。GQA 就是为了减小 KV Cache。

scores = q @ k.transpose(-2,-1) / math.sqrt(d)

### 🆘 Softmax 数值稳定性
> "标准 softmax 会溢出，稳定版本是 `exp(x - max(x)) / sum(...)`，减最大值不改变结果但防溢出。"
